# Test Express API

A simple Express.js API with basic endpoints for testing purposes.

## Features

- Basic REST API endpoints
- CORS enabled
- Environment variables support
- Error handling
- Simple data responses

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/MeghVyas3132/test-express-api.git
   cd test-express-api
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Create a `.env` file (optional):
   ```bash
   PORT=3000
   ```

4. Start the server:
   ```bash
   npm start
   ```

## API Endpoints

- GET `/`: Welcome message and API status
- GET `/api/test`: Sample data endpoint

## Deployment

This API can be easily deployed to platforms like:
- Heroku
- Railway
- Render
- DigitalOcean App Platform
